10 分钟搞定 Waline 评论系统：Vercel + MongoDB Atlas 全免费方案

从 MongoDB Atlas 数据库到 Vercel Serverless 部署，再到 Hugo Stack 主题配置，一份能直接照着做的 Waline 评论系统搭建教程，全程 0 元

2026-10-21
阅读时长: 4 分钟
loading... 次

为什么换 Waline？之前用 Giscus（GitHub Discussions）体验不错，但有个硬伤：读者必须有 GitHub 账号才能评论。对个人博客来说，这个门槛太高了。

Waline 的优势：

  • 支持匿名评论（填昵称 + 邮箱就行）
  • 完全免费开源（MIT 协议）
  • 前后端分离，前端一行 <script> 就能接入
  • Stack 主题原生支持，深浅色完美跟随
  • 自带浏览量统计、多级嵌套回复、表情、垃圾评论过滤

这篇文章记录我实际搭建的完整过程：Vercel（后端）+ MongoDB Atlas（数据库）+ Hugo Stack 主题，全程 0 元，不用服务器，10 分钟搞定。

第一部分：MongoDB Atlas（数据库）

注册 + 创建免费集群

  1. 打开 https://www.mongodb.com/cloud/atlas/register
  2. 邮箱注册（可用 GitHub 邮箱）
  3. 创建第一个 Project，名字随便（比如 whyblog）
  4. 点 Build a Database → 选 M0 Sandbox（免费）
  5. Region 选 Singapore 或 Tokyo（离国内近，延迟低）
  6. Cluster Name 随便（比如 whyblogcluster）
  7. 等 1~2 分钟，集群变成 Running

创建数据库用户

集群 Running 后点 Connect 按钮：

3
4

8

弹出框 → 选 Drivers（中间那个）

然后：
1. Create a Database User
2. Username: waline_user（随便起）
3. Password: 自己设一个强密码（记好！）
4. 权限选 Read and write to any database
5. Create User

放开网络访问（重要！）

默认只有你当前 IP 能访问，要放开给 Vercel（IP 会变）：

  1. 左侧菜单 → Network Access
  2. 点 Add IP Address
  3. 选 Allow Access from Anywhere → 自动填 0.0.0.0/0
  4. Confirm & Close

复制连接串 🔑

回到集群卡片 → Connect → Drivers：

复制这行（从 mongodb+srv:// 开始到末尾）：

1

mongodb+srv://waline_user:你的密码@whyblogcluster.p6mjbul.mongodb.net/?retryWrites=true&w=majority

⚠️ 如果密码里有 @ : / ? # 这些特殊字符，粘进连接串前要先 URL 编码。在线编码工具：https://www.urlencoder.org/

第二部分：Vercel 部署 Waline 后端

删之前的错误项目（如果有）

如果你之前手动 Import 过 walinejs/waline 主仓库（一个几十 MB 的 monorepo），那个是错的。Vercel 把它当成静态站处理，返回的是 HTML 页面而不是 JSON API。

Vercel Dashboard → Projects → 点错项目 → Settings → 拉到底 → Delete Project

⚠️ 关键：必须走官方一键部署

不要手动 Import 任何仓库！ 官方会自动创建一个轻量的 @waline/vercel 模板仓库（只有 server 代码）。

浏览器访问 → https://waline.js.org/guide/deploy/vercel.html

页面上方有一个绿色的 Deploy to Vercel 按钮，点它！

Vercel 创建项目

点按钮后 Vercel 自动弹出 Create Project 页面：

  • Repository Name：waline-server（Vercel 会自动帮你在 GitHub 创建仓库）
  • 其他字段：全部保持默认不要改！

先加环境变量再 Deploy

往下滚找到 Environment Variables，逐条添加（共 4 条）：

# KEY VALUE
1 MONGO_URI 第一部分复制的完整连接串
2 MONGO_DB waline
3 SITE_URL 你的博客地址，比如 https://whyboystudy.github.io/
4 SITE_NAME 博客名，比如 美味芝士

点击 Deploy 🚀

滚回页面顶部，点大的 Deploy 按钮。等 1~2 分钟，状态变成 ✅ Ready。

✅ 验证后端！

Deploy 成功后 Vercel 给你一个域名，格式类似：

1

https://waline-server-xxxxx.vercel.app

必须验证！ 浏览器打开那个域名，看到的应该是：

1

{"errno":0,"data":[]}

如果返回的是 HTML 页面或 Vercel 预览页 → 说明走错了，回去重新点官方 Deploy 按钮。

params:

    waline:
      serverURL: https://你的-waline-域名.vercel.app
      lang: zh-CN

      emoji:
        - https://unpkg.com/@waline/emojis@1.0.1/weibo
      requiredMeta:
        - name              # 必填：昵称
        - email             # 必填：邮箱
        # - url              # 注释掉就是可选的
      locale:
        admin: 美味芝士
        placeholder: 留下你的评论吧～

1

打开任意一篇文章（不是首页），往下滚：

  • Waline 评论区应该出现
  • 可以填昵称 + 邮箱 + 内容 → 提交评论

第四部分：可选的美化

给 Vercel 加个友好域名

Vercel Dashboard → Settings → Domains → 输入 whyblog-waline → Add
以后就是 https://whyblog-waline.vercel.app，不再是那串随机后缀。

自定义 Waline 样式

开启垃圾评论过滤

Waline 支持 Akismet 反垃圾（免费版即可）。在 Vercel 的环境变量里再加两条：

KEY VALUE
AKISMET_KEY 去 https://akismet.com/development/api/ 申请
AKISMET_SITE 你的博客地址

然后 Redeploy 就行。

第五部分：日常运维

操作 去哪做
看评论数据 MongoDB Atlas → Collections → 选 waline 数据库
手动删评论 Atlas 里找到 comments collection → 删除对应行
改环境变量 Vercel → Settings → Env Vars → 改完 Redeploy
升级 Waline GitHub 上的 waline-server 仓库 → Sync from upstream
备份评论数据 Atlas → Database → 你的集群 → Backup → Create Snapshot
换评论系统 hugo.yaml → comments.provider 改回 giscus / 其他

常见问题排查

现象 原因 解决
评论区完全空白 后端冷启动 / serverURL 写错 等 30 秒刷新 / 检查域名
提交报 Mongo 连接错误 Atlas 的 Network Access 没放开 加 0.0.0.0/0 规则
提交报密码错 MONGO_URI 密码写错或没编码 检查特殊字符
浏览量一直是 0 浏览器 Console 有跨域错误 确认 serverURL 和博客同 https
Giscus 和 Waline 同时出现 provider 没改干净 确认只有 provider: waline

和 Giscus 对比

Giscus Waline
是否需要 GitHub 账号评论 ❌ 必须 ✅ 支持匿名
是否需要后端部署 ❌ ✅ 10 分钟
数据归属 GitHub Discussions 你自己的 MongoDB
深浅色跟随 Stack ✅ ✅

Giscus 胜在零运维，Waline 胜在匿名评论和完全独立。两者都是免费的，如果你觉得读者注册 GitHub 门槛太高，Waline 是更好的选择。

总结

Waline 评论系统搭建的核心步骤：

  1. MongoDB Atlas：创建 M0 集群 → 建用户 → 放开网络 → 复制连接串
  2. Vercel：点官方 Deploy 按钮 → 加 4 条环境变量 → 等 Ready → 验证返回 JSON
  3. Hugo：改 hugo.yaml 的 comments.provider: waline → 填 serverURL → 预览测试

整体过程 10 分钟以内，全程浏览器操作，不用服务器，不用 Docker，不用 SSH。三个免费服务加起来一分钱不花，够个人博客用到天荒地老。
